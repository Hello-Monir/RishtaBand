## 🎯 Project Overview

**RishtaBand** is a modern, industry-standard **matrimonial website** crafted entirely in vanilla HTML, CSS, and JavaScript — demonstrating that exceptional UI/UX requires no dependency overhead.

The project targets South Asian matrimonial audiences with a warm, luxury-editorial aesthetic built around **rose-gold, ivory, and deep walnut** tones — evoking trust, elegance, and cultural warmth.

### 🎪 What makes this special?


## 🚀 Getting Started

### Prerequisites

```
✔ Any modern web browser  (Chrome 90+, Firefox 88+, Safari 14+, Edge 90+)
✔ A code editor           (VS Code recommended)
✔ No Node.js required
✔ No package manager required
✔ No internet required    (fonts load from Google Fonts — optional)
```

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/yourusername/rishtaband.git

# 2. Navigate into the project
cd rishtaband

# 3. Open in browser
#    macOS
open index.html

#    Windows
start index.html

#    Linux
xdg-open index.html

# ─── OR ───────────────────────────────────────────
# Open with VS Code Live Server (recommended for dev)
code .
# Then right-click index.html → "Open with Live Server"
```

```bash

# Drag the project folder to https://app.netlify.com/drop

git add .
git commit -m "feat: initial release"
git push origin main
# Then: Settings → Pages → Source: main / root

# ── Vercel ────────────────────────────────────────
npx vercel --prod
```

## ⚙️ JavaScript Modules

The `script.js` file is organized into clearly commented modules:

```
script.js
│
├── 🔄  PRELOADER          — Hides loader after window load, triggers hero animations
├── 🖱️   CUSTOM CURSOR      — Dual cursor with RAF loop, hover expand effect
├── 🧭  NAVBAR             — Scroll-based class toggle, mobile menu, active links
├── 👁️   REVEAL ON SCROLL   — IntersectionObserver for .reveal elements with stagger
├── 🔢  ANIMATED COUNTER   — Ease-out cubic number count-up for hero stats
├── 🌸  FALLING PETALS     — DOM-based petal spawn with randomized style/timing
├── 🔍  PROFILE FILTER     — Filter tiles by data-type attribute
├── ❤️   LIKE BUTTON        — Toggle liked state + heart burst particle effect
├── 🎠  TESTIMONIAL SLIDER — Auto-play, dots, prev/next, touch/swipe, responsive
├── 📋  MODAL SYSTEM       — Register/login with mode switching
├── 📬  CONTACT FORM       — Submit state, reset, toast feedback
├── 🔔  TOAST              — Lightweight global notification system
├── 🌊  PARALLAX ORBS      — mousemove-based depth on hero background elements
├── 📊  SCROLL PROGRESS    — Dynamic progress bar injected at top of viewport
└── 🪟  STAGGER REVEALS    — Section-level IntersectionObserver for step cards
```

## 🔧 Customization Guide

### Change the color palette
Edit CSS variables in `:root` inside `style.css`:

```css
:root {
  --gold:       #c9935a;   /* ← change this to your brand color */
  --rose:       #b5647a;   /* ← change accent color */
  --ivory:      #fdf8f2;   /* ← change background */
  --dark:       #1a1208;   /* ← change dark tone */
}
```

### Add a new profile tile
Copy any `.profile-tile` block in `index.html` and update:
- `data-type="bride"` → `bride` | `groom` | `bride verified`
- Avatar letter in `.tile-avatar`
- Gradient colors in `.tile-photo` style attribute
- Name, city, profession, tags in `.tile-body`

### Add a new testimonial
Copy any `.testi-card` inside `#testiTrack` and update the content. The slider auto-adjusts dot count.

### Change fonts
Replace the Google Fonts `<link>` in `index.html` and update `--font-serif` / `--font-sans` in `:root`.

### Adjust petal speed / volume
In `script.js`, find the **FALLING PETALS** section:
```javascript
setInterval(createPetal, 600);   // ← lower = more petals
petal.style.animationDuration = (6 + Math.random() * 8) + 's';  // ← lower = faster
```

### Change testimonial auto-play speed
```javascript
autoSlideTimer = setInterval(nextSlide, 4500);  // ← ms between slides
```

**Optimizations applied:**
- `will-change` and GPU-composited properties used for animations (`transform`, `opacity`)
